## 🛒 My Shop Flutter

Мобильное приложение-магазин на Flutter с интеграцией каталогов продуктов и рецептов. Позволяет просматривать товары, формировать корзину, оформлять заказы, читать отзывы и подбирать рецепты с учетом продуктов и пищевой информации.

### ✨ Основные возможности

#### 🧺 Магазин и заказы

- **Каталог товаров**
  - Список товаров с изображениями, ценой и описанием  
  - Детальная информация о продукте (бренд, категории, состав, питательные данные из OpenFoodFacts)
- **Корзина**
  - Добавление/удаление товаров  
  - Изменение количества  
  - Автоматический пересчет итоговой суммы
- **История заказов**
  - Список оформленных заказов  
  - Состав заказа и сумма  
  - Локальное хранение истории в SQLite

#### 🍽 Рецепты и питание

- **Рецепты (TheMealDB API)**
  - Поиск рецептов по названию
  - Просмотр детальной информации о блюде (ингредиенты, инструкции)
  - Получение случайного рецепта "блюдо дня"
  - Поиск похожих рецептов по категории
  - Поиск по ингредиентам
- **Продукты (OpenFoodFacts API)**
  - Поиск продуктов по названию
  - Популярные продукты и список по категориям
  - Просмотр нутриентов, ингредиентов, ярлыков (labels)
  - Фильтрация по странам происхождения (например, Russia)

#### 👤 Пользователь и взаимодействие

- **Авторизация**
  - Экран входа и регистрации
  - Защищенные экраны доступны только авторизованным пользователям
- **Профиль**
  - Просмотр и редактирование персональных данных
  - Локальное сохранение профиля
- **Отзывы**
  - Оставление отзывов и оценок
  - Список отзывов, хранящихся локально
- **Подписка и поддержка**
  - Экран подписки (subscription)
  - Экран поддержки (support) для связи/обратной связи

#### ⚙️ Настройки и удобство

- **Настройки**
  - Переключение темы: светлая/темная
  - Включение/выключение уведомлений
  - Сохранение настроек через `SharedPreferences`
- **Безопасность**
  - Хранение конфиденциальных данных (например, токенов) через `flutter_secure_storage`
- **Оффлайн-режим**
  - Корзина, заказы, профиль, отзывы и подписка хранятся в локальной базе (`sqflite`)

## 🏗️ Архитектура проекта

Проект организован с разделением на слои, близким к принципам Clean Architecture:

- **`data/`** – работа с данными (API клиенты, локальная БД, реализации репозиториев)
  - `data_sources/` – `LocalDatabase`, `OpenFoodFactsApiClient`, `MealDbApiClient`
  - `repositories/` – реализации доменных репозиториев
  - `providers/` – DI-провайдеры репозиториев
- **`domain/`** – бизнес-модели и абстракции
  - `models/` – `Product`, `FoodProduct`, `OrderRecord`, `Profile`, `Recipe`, `Review` и др.
  - `repositories/` – интерфейсы репозиториев
  - `use_cases/` – (зарезервировано под бизнес-логику)
- **`ui/`** – презентационный слой
  - `features/` – экраны и состояние по фичам (`auth`, `cart`, `product_list`, `food_products`, `recipes`, `profile`, `reviews`, `settings`, `subscription`, `support`, `main_screen`)
  - `utils/` – утилиты для UI (например, `price_formatter.dart`)
- **`app_router.dart`** – конфигурация навигации на `go_router` с учетом состояния авторизации

## 🗄️ Локальная база данных

Приложение использует `sqflite` для работы с локальной SQLite-базой (`my_shop.db`). Хранятся следующие сущности:

- **Заказы (`orders`)**
  - `id`, `total`, `date`, `status`
- **Позиции заказа (`order_items`)**
  - `order_id`, `product_id`, `product_name`, `quantity`, `price`
- **Корзина (`cart_items`)**
  - `product_id`, `product_name`, `product_description`, `product_price`, `quantity`, `image_url`
- **Профиль пользователя (`user_profile`)**
  - `first_name`, `last_name`, `email`, `updated_at`
- **Отзывы (`reviews`)**
  - `rating`, `text`, `created_at`
- **Подписки (`subscriptions`)**
  - `type`, `subscribed_at`

Миграции обрабатываются в методе `_onUpgrade` (например, добавление поля `image_url` в `cart_items`).

## 🌐 Интеграции с внешними API

### OpenFoodFacts API

Используется для работы с продуктами:

- Поиск продуктов по названию
- Получение продукта по штрих-коду
- Получение популярных/случайных продуктов
- Поиск по категориям и странам происхождения

**Базовый URL**:  
`https://world.openfoodfacts.org`

### TheMealDB API

Используется для работы с рецептами:

- Поиск рецептов по названию
- Получение рецепта по ID
- Получение случайного рецепта
- Поиск похожих рецептов по категории
- Поиск рецептов по ингредиенту

**Базовый URL**:  
`https://www.themealdb.com/api/json/v1/1`

## 📱 Основные экраны и маршруты

- `/login` – экран логина  
- `/register` – экран регистрации  
- `/` – главный экран (`MainMenuScreen`)  
- `/products` – список продуктов (интеграция с OpenFoodFacts)  
- `/recipes` – рецепты (TheMealDB)  
- `/cart` – корзина  
- `/cart/order_history` – история заказов  
- `/profile` – профиль пользователя  
- `/profile/change` – изменение данных профиля  
- `/reviews` – список отзывов  
- `/reviews/add_review` – добавление отзыва  
- `/settings` – настройки (тема, уведомления)  
- `/subscription` – подписка  
- `/support` – поддержка

Доступ к защищенным маршрутам контролируется через состояние авторизации (`authStateProvider`) в `app_router.dart`.

## 🔒 Безопасность

- Конфиденциальные данные (например, токены) хранятся в `flutter_secure_storage`
- Настройки и простые данные – в `SharedPreferences`
- Локальные пользовательские данные (заказы, корзина, профиль, отзывы) – в SQLite
